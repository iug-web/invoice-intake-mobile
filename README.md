# 手机入库单据助手

独立的浏览器本地工具，支持手机拍照、单据 OCR、分类建议、手动核对、CSV 导出和本地草稿。

## 使用

打开网页后，选择「手机直接拍照」或上传清晰的单据图片，逐行核对商品名称、数量、单位和每件单价，再保存或导出。初次识别需下载中文和英文模型。

## 数据与限制

- 照片、识别文字和草稿只在当前设备浏览器处理，不上传到 GitHub 或二维火。
- 草稿保存在当前设备、当前浏览器；不跨设备同步。清理网站数据会删除草稿，请导出备份。
- OCR 和分类只是建议，需要人工核对，尤其是品名、单位与价格。
- **本工具尚未接入二维火正式库存接口，不会自动提交入库记录。**
- 手机及 Windows 浏览器均可访问。实际手机相机、国内移动网络和 Windows 真机仍需用户设备验收。

## 部署

静态文件在 main 分支根目录。使用 GitHub Pages，发布源选择 main / (root)。不需要服务器密码或二维火账号。

第三方组件来源见 vendor/README.md，许可证见 vendor/APACHE-2.0.txt。
